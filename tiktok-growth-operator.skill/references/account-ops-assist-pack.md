# Account Ops Assist Pack

Use this pack when the user wants a Codex-native replacement for the platform's account-operations and inbox-assist layer, driven by real TikTok account exports instead of a hosted dashboard.

## Goal

Produce one reusable account-operations pack for:

- inbox reply monitoring
- notice and notification review
- following-request triage
- following and follower watch
- safe response drafting

## Inputs

- newest reply export
- notice export
- following request export
- following list or follower list export
- optional live-following export
- account positioning notes
- optional moderation or escalation rules

## Outputs

- account operations summary
- inbox signal summary
- notice radar
- following-request queue
- relationship watch
- safe response prompts
- escalation rules
- daily review checklist

Do not claim auto-reply, auto-approve, auto-message, or inbox mutation unless a real approved downstream executor exists.
