# Publish Prep Pack

Use this pack when the user wants a Codex-native replacement for the article's "automatic publish" layer without pretending cloud-phone RPA exists.

## Goal

Produce a ready-to-execute publish handoff pack for one planned TikTok or Douyin video.

## Inputs

- project or product name
- target platform: TikTok or Douyin
- target market
- optional script or video brief
- optional product assets
- optional account positioning notes

## Outputs

- publish summary
- title variants
- hook variants
- caption variants
- hashtag set
- cover direction
- manual publish checklist
- post-publish review checklist
