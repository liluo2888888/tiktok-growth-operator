# Deliverable Contracts

## Default Output Rule

Every scene should end with:

1. concise executive conclusion
2. core evidence or logic
3. reusable next action

## Common Deliverable Types

### 1. Collection board

Use for scenes 1, 2, 6, 18.

Should include:

- object list
- why each object matters
- fields to track next time

Default seeded sections:

- Executive Conclusion
- Objects To Track
- Why They Matter
- Fields To Capture Next Time
- Next Action

### 2. Breakdown report

Use for scenes 3, 4, 5, 17.

Should include:

- one-line conclusion
- structural logic
- reusable formula
- risks and adaptation notes

Default seeded sections:

- Executive Conclusion
- Structure Logic
- Core Mechanism
- Reusable Formula
- Risks And Adaptation Notes
- Next Action

### 3. Insight report

Use for scenes 7, 8, 19.

Should include:

- high-level judgment
- evidence clusters
- recommended action

Default seeded sections:

- Executive Conclusion
- High-Level Judgment
- Evidence Clusters
- Recommended Action
- Open Questions

### 4. Creation brief

Use for scenes 9, 10, 13, 15, 16.

Should include:

- target
- audience
- message
- structure
- creative constraints
- localization or adaptation requirements

Default seeded sections:

- Executive Conclusion
- Target
- Audience
- Message
- Structure
- Creative Constraints
- Next Action

### 5. Testing matrix

Use for scenes 11, 12, 14.

Should include:

- core invariant
- variable rows
- expected effect
- what to learn from each variant

Default seeded sections:

- Executive Conclusion
- Core Invariant
- Variable Matrix
- Expected Effect
- What To Learn
- Next Action
