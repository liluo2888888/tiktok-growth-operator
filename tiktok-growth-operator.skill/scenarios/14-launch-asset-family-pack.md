# Scene 14: Launch Asset Family Pack

## Use When

- the user wants a complete new-product asset plan

## Minimum Inputs

- product description

## Ideal Inputs

- product images
- selling points
- target market
- platform constraints

## Workflow

1. define the minimum launch asset family
2. map each asset to its job
3. write one coherent creative direction
4. output image/video requirements together

## Output Contract

- asset list
- purpose of each asset
- creative direction
- production priority

## Direct Prompt

```text
请为这个产品设计一套“上新素材全家桶”。

至少包括：
1. 白底主图
2. 场景图
3. 卖点图
4. 细节图
5. 配套短视频方向

并告诉我每个素材分别承担什么转化任务。
```

## Fallback

If images are missing, produce the asset blueprint and shot list first.
