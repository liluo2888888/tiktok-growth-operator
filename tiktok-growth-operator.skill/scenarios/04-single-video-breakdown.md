# Scene 4: Single Video Breakdown

## Use When

- the user gives one TikTok or Douyin video and wants the full logic explained

## Minimum Inputs

- one video link, transcript, screenshots, or storyboard

## Ideal Inputs

- link
- transcript
- frame notes
- performance metrics

## Workflow

1. identify platform and content type
2. reconstruct hook, structure, proof, and CTA
3. separate core mechanism from surface styling
4. state what is reusable
5. suggest one safer and one more aggressive adaptation

## Output Contract

- one-line judgment
- structure map
- viral mechanism
- reusable formula
- adaptation advice

## Direct Prompt

```text
请完整拆解这条短视频。

要求：
1. 解释它为什么能抓人
2. 解释它如何证明和转化
3. 区分真正的底层逻辑与表面风格
4. 告诉我应该抄哪部分，不该抄哪部分
```

## Fallback

If only the link exists but no accessible content, ask for screenshots, subtitles, or a short manual summary.
