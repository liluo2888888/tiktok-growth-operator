# Scene 10: Product-Image-to-Video Brief

## Use When

- the user wants to generate a product video from product images only

## Minimum Inputs

- product images or a clear product description

## Ideal Inputs

- multiple product angles
- selling points
- target audience
- market language
- desired style

## Workflow

1. define audience and conversion goal
2. choose video type
3. design hook, scene order, and proof beats
4. design voiceover and text overlays
5. output a render-ready creation brief

## Output Contract

- video concept
- shot structure
- voiceover structure
- style keywords
- test variables

## Direct Prompt

```text
请只基于产品图片和卖点，帮我设计一条带货短视频创作简报。

我需要：
1. 视频类型建议
2. 3秒钩子
3. 分镜顺序
4. 口播结构
5. 视觉风格关键词
6. 适合测试的两个变量
```

## Fallback

If images are missing, use a product-description-only version and mark visual sections as pending.
