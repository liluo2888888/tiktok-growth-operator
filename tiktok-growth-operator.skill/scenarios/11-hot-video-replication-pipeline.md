# Scene 11: Hot-Video Replication Pipeline

## Use When

- the user wants one end-to-end workflow from finding hot videos to building fresh creative directions

## Minimum Inputs

- one category or product

## Ideal Inputs

- keyword set
- product assets
- target market
- testing goal

## Workflow

1. search and shortlist hot videos
2. choose the best replication candidates
3. summarize each candidate’s logic
4. build multiple replication briefs
5. output a daily/weekly creative pipeline

## Output Contract

- candidate ladder
- replication brief bank
- production queue
- testing recommendation

## Direct Prompt

```text
我要搭一个“热门视频追踪 + 批量复刻素材流水线”。

请帮我设计：
1. 如何从热点视频里筛参考对象
2. 如何快速拆逻辑
3. 如何把一个参考转成多条新素材方向
4. 如何组织成每天可复用的素材生产队列
```

## Fallback

If no live candidates exist yet, produce the pipeline template plus the exact collection checklist.
