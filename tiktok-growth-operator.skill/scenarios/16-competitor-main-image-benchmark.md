# Scene 16: Competitor Main-Image Benchmark

## Use When

- the user wants to compare their main image against competitors and design a stronger direction

## Minimum Inputs

- at least 2 competitor images and 1 user image or product

## Ideal Inputs

- click-through context
- platform
- category norms
- known strengths/weaknesses

## Workflow

1. compare visual category codes
2. identify what competitors are all doing
3. identify what is effective versus generic
4. propose one safer and one sharper differentiation direction

## Output Contract

- competitor comparison
- design weakness map
- outperform strategy
- revised main-image brief

## Direct Prompt

```text
请帮我做“竞品主图对标分析与超越方案”。

我需要：
1. 竞品主图共同套路
2. 哪些元素最可能影响点击
3. 我的图应该避免什么
4. 给我一版更能打的主图 brief
```

## Fallback

If the user has no own image yet, benchmark competitors first and write a “from zero” brief.
