# Scene 13: Multi-Market Localization Pack

## Use When

- the user wants one product adapted across multiple markets

## Minimum Inputs

- one product
- at least 2 target markets

## Ideal Inputs

- product visuals
- source script
- market list
- local audience notes

## Workflow

1. keep the same product core
2. identify what must change by market
3. localize language, talent archetype, visual cues, and cultural references
4. output a per-market pack

## Output Contract

- shared invariant
- per-market localization notes
- per-market hook and script direction
- per-market visual cues

## Direct Prompt

```text
请把这个产品做成“多市场本地化视频包”。

市场：<市场列表>

请分别输出：
1. 每个市场的受众感觉
2. 适合的出镜人物/场景
3. 口播语气和关键词
4. 3秒钩子
5. 需要避开的表达
```

## Fallback

If there is no original script yet, localize the concept and hook first, then leave script lines as next-step work.
