# Scene 9: Reference-Video Replication Brief

## Use When

- the user has a reference TikTok video and wants a new version for their product

## Minimum Inputs

- reference link or breakdown
- user product info

## Ideal Inputs

- product images
- product selling points
- target audience
- target market

## Workflow

1. break down the reference logic
2. identify invariant pieces
3. identify product replacement points
4. rewrite the brief for the new product
5. output script, structure, and shot guidance

## Output Contract

- replication brief
- adapted hook
- adapted proof sequence
- shot order
- optional voiceover draft

## Direct Prompt

```text
请基于这个参考视频，为我的产品做一份“爆款复刻执行简报”。

要求：
1. 保留原视频有效的底层逻辑
2. 把产品、卖点、场景全部换成我的
3. 不要照搬成片，要做成我后续能继续生成或拍摄的执行文档
```

## Fallback

If no product details exist yet, stop after the reference logic and ask for product inputs.
