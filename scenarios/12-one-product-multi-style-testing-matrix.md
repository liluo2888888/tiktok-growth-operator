# Scene 12: One-Product Multi-Style Testing Matrix

## Use When

- the user wants multiple creative directions for one product

## Minimum Inputs

- one product
- one target market

## Ideal Inputs

- product images
- target audience
- selling points
- constraints on tone or creator type

## Workflow

1. define the invariant core message
2. define 4-6 creative styles
3. map each style to hook, proof, and CTA differences
4. build a testing matrix
5. output which style should be tested first

## Output Contract

- style matrix
- hook variants
- proof variants
- testing order

## Direct Prompt

```text
请为同一个产品设计“一品多素材测试矩阵”。

我需要至少 4 种风格，每种都写清：
1. 人群
2. 钩子
3. 核心卖点证明方式
4. 视频风格
5. 为什么值得测
```

## Fallback

If product assets are thin, keep the matrix high-level and flag which rows need image or usage evidence.
