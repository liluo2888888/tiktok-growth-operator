# Scene 7: Category Market Insight

## Use When

- the user wants to know whether a category is worth entering

## Minimum Inputs

- one category or product theme

## Ideal Inputs

- top videos
- category keywords
- competitor products
- target market

## Workflow

1. map the category keywords
2. study top content themes
3. identify visible demand and angle saturation
4. identify what seems underserved
5. output go / no-go / priority view

## Output Contract

- category judgment
- hot angle map
- saturation notes
- opportunity notes
- recommendation

## Direct Prompt

```text
请把这个品类做成一份“市场洞察深度分析报告”。

我关心：
1. 这个品类在 TikTok 上热不热
2. 内容都在怎么卖
3. 哪些角度已经卷了
4. 哪些空位还值得做
5. 最终我该不该做，优先级多高
```

## Fallback

If live data is missing, ask for category video samples or search screenshots before making a hard recommendation.
