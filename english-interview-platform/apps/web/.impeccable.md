# Quest English — Design Context

Skills: `E:\前端\skills` (frontend-design, ui-ux-pro-max, teach-impeccable, web-design-guidelines).

## Design Context

### Users

Non-native English speakers preparing for real job interviews. Often anxious, time-boxed, practicing between applications on laptop or phone.

### Brand Personality

**Editorial interview coach** — warm parchment, ink typography, copper/brass accents (passport metaphor). Calm confidence, not gamified candy. A refined practice workbook.

### Aesthetic Direction

- **Typography**: Fraunces (display) + IBM Plex Sans (body)
- **Color**: OKLCH warm paper + copper accent (`--hue-brand: 38`)
- **Motif**: Passport stamps, perforation edges, interview-room focus panel
- **Anti-references**: Purple gradients, Inter-only UI, emoji icons, generic card dashboards

### Design Principles

1. **Editorial hierarchy** — One strong headline, restrained body, left-border accents over card grids.
2. **SVG, not emoji** — Icons via `Icon` component; emojis never as navigation or system UI.
3. **Motion with meaning** — Staggered page reveal; respect `prefers-reduced-motion`.
4. **Accessible by default** — Skip link, visible focus, labels on inputs, 4.5:1 contrast.
5. **Interview focus** — Dark question panel + light answer area; single primary CTA per screen.
