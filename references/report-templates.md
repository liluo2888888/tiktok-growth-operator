# Report Templates

Use these shapes when converting Clipcat-style outputs into Codex-delivered reports.

## 1. Viral Breakdown Report

Preferred structure:

1. case header
2. one-paragraph summary
3. per-video basic info
4. hook analysis
5. proof/conversion rhythm
6. visual structure
7. repeated cross-case patterns
8. content creation rules
9. one-line formula

Short template:

```md
# <topic> 爆款视频拆解报告

## 概览
- 样本:
- 地区:
- 时间:
- 核心判断:

## TOP 视频拆解
### TOP 1
- 基本信息:
- 钩子:
- 证明方式:
- 画面结构:
- 转化逻辑:

### TOP 2
...

## 共性规律
1. 钩子规律
2. 转化节奏
3. 画面风格

## 创作建议
- 开头公式:
- 节奏模板:
- 话术技巧:
- 优先测试类型:

## 结论公式
<formula>
```

## 2. Category Insight Report

Preferred structure:

1. category scope
2. search evidence
3. hot keywords
4. content pattern clusters
5. product/performance signals
6. go / no-go / priority recommendation

## 3. Comment Mining Report

Preferred structure:

1. sampled products
2. repeated praise
3. repeated complaints
4. unmet needs
5. persona summary
6. product opportunity notes

## 4. Account Distillation Report

Preferred structure:

1. account overview
2. top-performing content patterns
3. recurring hook formulas
4. pacing and shot patterns
5. CTA and conversion style
6. how to adapt for the user’s product

## 5. Replication Brief

Use before any generation call:

```md
# 爆款复刻执行简报

## 参考对象
- URL:
- 平台:
- 核心风格:

## 不变部分
- 钩子逻辑:
- 节奏结构:
- 画面节拍:

## 必改部分
- 产品植入:
- 卖点:
- 语言:
- 市场:

## 风险
- 过度照搬:
- 时长不匹配:
- 语言/文化不适配:

## 建议执行参数
- model:
- duration:
- size:
- lang:
- images:
```

## 6. Paid Execution Confirmation Block

Show this before `replicate`, `product_video`, or `image`:

```md
计划执行以下 Clipcat 命令：

<command>

原因：
- ...

这一步会消耗算力/积分，并且是异步任务。
确认后我再执行。
```
