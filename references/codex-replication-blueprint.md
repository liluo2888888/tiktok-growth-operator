# Codex Replication Blueprint

## Design Principle

“完全复刻” here means:

1. every source scenario exists as a callable Codex workflow
2. every workflow has minimum inputs, output contracts, and direct prompts
3. the package remains useful even without Clipcat CLI

## Reproduction Layers

### Layer 1: scene parity

The 19 scenes are recreated one by one.

### Layer 2: operator parity

Each scene includes:

- what to collect
- how to reason
- what to output
- how to continue

### Layer 3: delivery parity

Each scene produces a tangible output:

- report
- matrix
- brief
- checklist
- prompt pack

## Pure Codex Substitutes

### Instead of live TikTok Shop API

Use:

- user-supplied screenshots
- user-supplied product links
- browsed public evidence when available
- competitor review exports
- category keyword packs

### Instead of built-in generation backend

Produce:

- replication brief
- product-video brief
- prompt pack
- storyboard
- testing matrix

### Instead of one-click scheduled patrol

Produce:

- reusable patrol template
- daily/weekly checklist
- ready-to-run report skeleton

## Quality Bar

A recreated scene is considered done only if it has:

- trigger conditions
- minimum inputs
- ideal inputs
- workflow
- output contract
- direct prompt
- fallback path
