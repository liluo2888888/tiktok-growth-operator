# Live Assist Pack

Use this pack when the user wants a Codex-native replacement for the article's "live-room assist" layer without pretending there is a real telemetry or moderation bot.

## Goal

Produce a reusable live-room operator pack for one TikTok or Douyin live session.

## Inputs

- live topic or product
- target platform: TikTok or Douyin
- target market
- host style or account positioning
- optional FAQ, objections, or product notes
- optional promotion or offer notes

## Outputs

- live summary
- session objective
- run-of-show
- host prompt bank
- moderator reply bank
- objection handling table
- anomaly checklist
- escalation rules
- live review checklist

## Recommended Sections

1. Session Goal
2. Audience And Buying Context
3. Run Of Show
4. Host Prompt Bank
5. Moderator Reply Bank
6. Objection Handling
7. Anomaly Checklist
8. Escalation Rules
9. Post-Live Review Checklist

## Minimum Truthfulness Rule

Do not claim live telemetry, OCR, comment polling, or auto-moderation unless those systems actually exist.
