# Creative Production Handoff Pack

Use this pack when the user wants a Codex-native bridge from scene `09` to `16` briefs into something editing, design, scripting, or localization owners can execute directly.

## Goal

Produce a production-ready creative handoff pack for one short-video asset, asset family, localization branch, or benchmark-driven redesign direction.

## Inputs

- project or asset-set name
- target platform: TikTok or Douyin
- target market
- optional structured scene report JSON
- optional product assets, script, layout capture, or benchmark notes
- optional owner, review, or production constraints

## Outputs

- creative objective
- invariant logic
- asset and evidence readiness view
- execution blueprint
- variant or market plan
- production handoff table
- copy-ready role prompts for script, design, localization/review, and production coordination
- review gates
- open risks
- immediate next production step

## Minimum Truthfulness Rule

Do not imply assets, proof, localization review, render capacity, or production owners already exist unless the source report or user evidence confirms them.
