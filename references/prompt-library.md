# Prompt Library

Use these shared blocks inside scene workflows instead of rewriting from scratch.

## A. Viral Ranking Prompt

```text
你现在是 TikTok 爆款筛选员。基于我提供的候选视频列表，不要平均分析，而是先排序。
目标：
1. 识别最值得研究的 3-10 条
2. 解释为什么值得研究
3. 区分“只是数据高”和“真正可复用”
输出：
- Top 清单
- 每条的核心看点
- 可复用程度
- 适配什么产品和内容方向
```

## B. Single Video Breakdown Prompt

```text
你现在是 TikTok 爆款拆解师。请拆解这条视频，不要停留在表面描述，而是解释：
1. 3 秒钩子怎么抓人
2. 中段如何证明
3. 节奏如何推进
4. 为什么用户会继续看、点赞、评论或下单
5. 哪些部分可复用，哪些部分只是表面风格

输出：
- 一句话结论
- 结构拆解
- 爆点机制
- 可复用公式
- 风险与改写建议
```

## C. Comment Mining Prompt

```text
请把这些商品评论当作用户真实声音，不要只做情感分析。
我要你提炼：
1. 用户最在乎的购买理由
2. 最常见的不满与痛点
3. 被反复提到但没有被满足的需求
4. 用户原话里的高频表达
5. 对选品、文案、视频脚本的启发
```

## D. Replication Brief Prompt

```text
请基于参考视频，为新产品生成“复制逻辑，不是照抄成片”的执行简报。
要求：
1. 保留原视频的钩子逻辑、证明节奏、镜头作用
2. 替换为我的产品卖点与使用场景
3. 给出可直接用于后续视频生成或脚本创作的版本
输出：
- 原视频底层逻辑
- 我方产品替换位
- 新脚本方向
- 镜头/分镜建议
- 口播改写建议
```

## E. Product Video Brief Prompt

```text
请只基于产品图片和卖点，设计一条带货短视频的创作简报。
输出：
- 目标受众
- 视频类型
- 钩子
- 镜头顺序
- 口播节奏
- 画面要求
- 风格关键词
- A/B 测试变量
```

## F. Creator Distillation Prompt

```text
请蒸馏这个博主或账号的内容打法。
我要的不是简介，而是：
1. 反复出现的钩子公式
2. 叙事节奏
3. 视觉风格
4. 证明方式
5. CTA 风格
6. 哪些能力来自人设积累，哪些是新账号也能复用的
```

## G. Retrospective Prompt

```text
请基于账号表现数据做复盘，不要只列数据。
输出：
- 哪些内容模式赢了
- 哪些内容模式输了
- 胜负差异的关键变量
- 接下来应该多做、少做、停止做什么
- 下一测试周期的明确动作
```
